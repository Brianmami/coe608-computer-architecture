# COE 608 Lab 4 – Data Memory and CPU Datapath

**Course:** COE 608 – Computer Organization and Architecture  
**Tools:** VHDL, Intel Quartus Prime

## Overview

- **Lab 4a:** data memory (`data_mem_lab4a.vhd`)
- **Lab 4b:** the full 32-bit datapath (`data_path.vhd`), which connects the PC, registers A/B, IR, ALU, data memory, multiplexers and the LZE/UZE/RED immediate-extension units

## Build / run

Open the `.qpf` project (or create one and add the `.vhd`/`.bdf` files) in Intel Quartus Prime, compile, then program the Altera DE2 board or simulate with the `.vwf` waveform file.
