# COE 608 Lab 2 – Registers and Program Counter

**Course:** COE 608 – Computer Organization and Architecture  
**Tools:** VHDL, Intel Quartus Prime

## Overview

Storage elements for the CPU built in later labs: a 1-bit register, a 32-bit register with load and clear, and a program counter (`pc.vhd`) that uses an adder and a 2-to-1 mux to increment or load a new address.

## Build / run

Open the `.qpf` project (or create one and add the `.vhd`/`.bdf` files) in Intel Quartus Prime, compile, then program the Altera DE2 board or simulate with the `.vwf` waveform file.
